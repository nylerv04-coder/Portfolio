PROJECT OVERVIEW

Developed a real-time radar scanning and target detection system using an Arduino Uno, an ultrasonic sensor, and a custom Python graphical interface. The system autonomously sweeps its environment, processes spatial data, and visually plots detected objects on a digital radar display while triggering on-board hardware alerts when a target is locked.

HARDWARE

An SG90 servo motor drives continuous sweeping motion across the scan arc. An HC-SR04 ultrasonic sensor mounts to the servo and fires at each angular position, returning distance readings via time-of-flight measurement. An LCD1602 display provides live on-board diagnostics including current sweep angle and target lock status. All components are orchestrated by an Arduino Uno running C++ firmware built on a non-blocking state machine, so motor actuation and sensor polling never interfere with each other.

SOFTWARE

A Python application reads the serial stream from the Arduino using PySerial, parses the incoming angle-distance data pairs, and converts polar coordinates to Cartesian positions on the display. The radar GUI is built with pygame and renders a live sweeping beam, persistent target markers, and distance scaling. Data polling rates and LCD refresh cycles were tuned to eliminate ghosting and keep the physical and digital systems synchronized.

FUTURE DEVELOPMENT

The next phase transitions from a breadboard prototype to a fully integrated mechanical assembly. Planned additions include a second servo axis for hemispherical pan-tilt coverage, a laser diode with autonomous tracking heuristics to aim at detected targets, and custom 3D-printed components for the sensor chassis, motor mounts, and electronics housing.
