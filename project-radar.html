AUTOMATED RADAR TRACKING SYSTEM

[RADAR_GUI_OR_HARDWARE_IMG]

PROJECT OVERVIEW

Developed a real-time radar scanning and target detection system using an Arduino Uno, an ultrasonic sensor, and a custom-built Python graphical interface. The system autonomously sweeps its environment, processes spatial data, and visually logs physical objects on a digital radar screen while providing local hardware alerts.

TECHNICAL IMPLEMENTATION & ACCOMPLISHMENTS

  • Hardware Integration: Configured an SG90 servo motor and HC-SR04 sensor to perform synchronized environmental sweeps. Integrated an LCD1602 digital display to provide live on-board diagnostics, including current sweep angles and "Target Locked" alerts.
  • Software Development: Engineered the C++ microcontroller logic using a state machine to handle scanning phases without blocking motor actuation.
  • Data Visualization: Built a custom Python application utilizing Pygame and PySerial. The software parses serial data structures from the Arduino and translates polar coordinates into a high-fidelity Cartesian radar display, complete with persistent target tracking and distance scaling.
  • System Optimization: Tuned the data polling rates and LCD refresh cycles to eliminate hardware ghosting and ensure a perfectly synchronized digital and physical tracking experience.

FUTURE SCOPE & PHASE 2 DEVELOPMENT

The next phase of this project will transition the system from a breadboard prototype to a fully integrated mechanical assembly. Key development goals include:

  • 2-Axis Articulation: Introducing a second servo motor to create a Pan/Tilt mechanism, expanding the tracking capabilities to a full hemispherical range.
  • Automated Turret Integration: Mounting a laser diode to the new actuator assembly and writing tracking heuristics to autonomously aim and follow detected targets.
  • Mechanical Design: Utilizing CAD software to design and 3D print custom structural components. This will include a rigid sensor chassis, optimized motor mounts, and an integrated electronics housing to clean up the wiring and improve overall system durability.
